# Axona Protocol Architecture Council — Logs & Transcripts Directory

This directory contains official council logs and full transcripts of `#council` discussions on `axona-chat` / `axona-protocol`, split by date for efficient access and maintenance.

## Operating Principles & Governance
1. **Active Files:** New council messages are appended to the current date's log (`COUNCIL-LOGS-YYYY-MM-DD.md`) and transcript (`COUNCIL-TRANSCRIPT-YYYY-MM-DD.md`).
2. **Review Integrity:** All code review dispositions (Aster, Orion, Vega) cite commit SHAs and test assertion outputs.
3. **Council Scribe:** Orion maintains and synchronizes this directory.
